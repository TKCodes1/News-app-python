# News App in Python

A simple desktop news application built with Python that fetches real-time headlines from BBC News using RSS feeds and displays them in a GUI made using Tkinter. You can browse headlines and click to open full articles in your browser.

---

## 📙Features:
- Live news fetched from RSS
- Scrollable feed
- Filter by keyword
- Clickable headlines

## 🧠What I learnt and used:
- Using RSS feeds
- Openning urls with webbrowser
- Filtering
- GUI creation with Tkinter

## 🧰Tools used:
- Python
- Tkinter
- RSS parsing
- webbrowser

## ▶️How to run:

```bash
pip install feedparser
python NewsApp.py
```
